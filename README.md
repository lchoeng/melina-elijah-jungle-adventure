# Melina & Elijah Jungle Adventure

A 9-level jungle platformer (each new level gets harder) for young kids starring Melina and Elijah.

- Collect coins and hidden dinosaur eggs
- Eat spicy noodles to breathe fire
- Stomp Mini Carnotaurus
- Single player or two-player co-op
- Levels: Jungle Trail, Vine River, Ancient Ruins, Misty Swamp, Lava Caves, Treetop Kingdom, Thunder Canyon, Night Jungle, Volcano Summit
- Beat the Giant Carnotaurus in Levels 3, 6 and 9, then reach the Tree House Castle

Open `index.html` in a browser to play. Works on phones (turn sideways) and with a keyboard:
P1 Melina: A/D move, W jump, F fire. P2 Elijah: arrow keys move/jump, Enter fire.
